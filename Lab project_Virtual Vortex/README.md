# Simulation & Modeling Lab Project  
### **Restaurant Tipping Behavior Analysis**

## 📄 **Project Overview**
This project focuses on analyzing restaurant tipping behavior using statistical modeling techniques. The goal is to identify the factors that influence how much customers tip based on various attributes such as total bill amount, table size, gender, smoking status, day, and time.

We used Python and statistical libraries to develop:
- Correlation analysis  
- Exploratory data analysis (EDA)  
- Linear regression modeling  
- Hypothesis testing  
- ANOVA  
- Model diagnostics  

This project demonstrates the practical application of simulation and modeling in real-world decision-making, particularly in restaurant management and customer behavior analysis.

---

## 📊 **Key Features**
- Visualizations (histograms, boxplots, countplots)
- Correlation heatmap
- Linear regression model
- Prediction analysis
- Hypothesis testing (t-test, Pearson correlation)
- ANOVA test
- Residual diagnostics
- Statistical interpretation of results

## ✔️ **Conclusion**
The analysis shows that **total bill amount** and **table size** are the strongest predictors of tip amount. The linear regression model and statistical tests confirm a positive relationship between the total bill and tipping behavior. Model diagnostics validate the reliability of the model, and the findings support real-world applications in restaurant service planning and customer behavior understanding.
